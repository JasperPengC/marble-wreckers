# 弹珠拆迁队 · 全屏沉浸式 UI 改版方案

## Context

现在是"街机机台"三段式布局:顶部 LED 仪表盘(`#deck-top`)、中间 CRT 屏幕(画布被 letterbox 在 `#screen-inner` 里,锁 400:660)、底部按键台(`#deck-bottom`:构筑条 + 暂停/玩法/撤退按钮)。要改成标准竖屏手游布局:

- **全屏主体**:Canvas 铺满整个视口,场地(400×660 逻辑区)居中,四周用延伸的天空/城市/地面 scenery 填满
- **悬浮 HUD**:资源数字(楼栋/热度/灵石/护盾)→ 顶部半透明小徽章;暂停等 → 圆形悬浮图标
- **主页底部 Dock**:大按钮「开始拆楼」+ Dock 5 项(每日挑战/强化商店/成就图鉴/技能图鉴/玩法说明),设置 = 右下角圆形悬浮齿轮
- **构筑条删除**:改为角落带角标小圆钮 → 点开全屏浮层(强化+遗物+砖块图例)
- **桌面(≥920px)**:同样全屏画布+悬浮 HUD,保留右侧作战面板
- **视觉**:完全干净的现代手游质感,不留 CRT 扫描线/机台边框

**Git 工作流**:从 `main` 新建特性分支 `feat/fullscreen-hud`,全部工作在分支上进行;每阶段跑 `bun run check` 控制回归,分支上全绿 + 手测通过后,再合并回 `main`。

**已确认的关键可行性**(探索结论):游戏层 `src/game/` 纯逻辑坐标、不碰画布,零改动;渲染器 `draw.ts:2710-2717` 用统一缩放(`scale = canvas.width/W`,1 逻辑像素 = 1 设备像素),改为 `scale = min(cw/W, ch/H)` + 场地偏移 `ox/oy` 即可全屏化,相机抖动/慢镜头的枢轴不变;指针瞄准 `main.ts:648-655` 是 rect 归一化,补上偏移即可。

## 改动分五个阶段

### Phase 1 — 渲染全屏化(`src/render/draw.ts` + `src/main.ts` 尺寸链)

1. `syncCanvasSize()`(main.ts:255-268):backing store 改为 `rect.width×dpr × rect.height×dpr`,删掉 400:660 比例推导
2. `fitScreen()`(main.ts:273-328,测量 deck 高度的 letterbox 引擎)整体替换为轻量 `fitCanvas()`:画布 CSS 直接全屏(CSS 负责),JS 只同步 backing;新增 `resize`/`orientationchange`/`visualViewport.resize` 监听(现在只有 20 帧轮询 + DPR 检查),删掉 deck 修正循环
3. 渲染器场地映射:每帧算 `scale = min(canvas.width/W, canvas.height/H)`(做设备像素对齐保住 1:1 清晰度)、`ox/oy` = 居中场地原点;`ctx.setTransform(scale,0,0,scale,ox,oy)`;相机块(2750-2754)枢轴 `(W/2, H/2)` 逻辑坐标不变,偏移由 transform 承载
4. **背景延伸**(工作量主体):烘焙层从 W×H 逻辑世界扩展为「场地 + 逻辑边距 mx=ox/scale, my=oy/scale」的世界矩形——天空渐变/星星/月亮铺满扩展区、天际线 march 到扩展宽度、地面下延、暗角带按扩展矩形;烘焙 regen 的 key 加入 margins(draw.ts:448-751 `buildBackgroundLayers`、206-257 场景数组、1512-1559 `drawBackground`);near/mist 条已有 tile 循环,扩 march 范围即可;`ensureSprites`/墙/砖 sprite 不动
5. `pointerAngle()`:逻辑坐标 = ((clientX−rect.left)·dpr − ox)/scale,补偏移;瞄准/拖拽手感不变
6. 屏幕空间元素核对:暗角/闪光/慢镜头渐变(3047-3067)改按扩展矩形;伤害弹字 `py=max(22,…)` 保持场内;Combo 文本 (W-18,66) 保持场内
7. 标题画面 attract 场景保持在场地区域内绘制,边距自然露出延伸 scenery
8. `BUILTIN_THEMES.viewport {W,H}`(main.ts:124)保持声明场地尺寸,不动

### Phase 2 — DOM/CSS 重构(`src/template.html` + `src/style.css`)

1. 新骨架(template.html 重写,`shell.html` 只有 head 不动):

   ```
   #app
   ├─ #board canvas(position:fixed inset:0)
   ├─ .hud-top(贴安全区,pointer-events:none)
   │   ├─ .hud-chips(左:楼栋/热度/灵石/护盾 4 个半透明徽章 + #save-led)
   │   └─ .hud-actions(右:#pause 圆形悬浮钮,局内显示)
   ├─ #build-fab(右下圆钮+数量角标,局内显示)  ← Phase 4
   ├─ #boss-bar / #banner / #danger / #notice(悬浮,贴安全区)
   └─ #overlay(改为 fixed 全屏场景层)
   ```
2. **保留全部 e2e 依赖的 id**:hud-tower/hud-score/hud-coins/hud-shield、pause、boss-bar/boss-fill、banner、danger、notice、overlay、board、data-led=coins——徽章只是换壳,id 不变,把 e2e 破坏面压到最小
3. 删除:cabinet/bezel/deck-top/deck-bottom/screen/screen-inner/screen__glass/ticker/joystick/ab-keys/panel-row/#retreat/#build-bar(撤退收进暂停面板——暂停场景里本来就有「结算并按灵石撤退」)
4. style.css 对应删改:cabinet(69-101)/bezel(103-148)/deck(173-194, 2532-2560, 3303-3314, 4677-4702)/screen+glass(317-369)/死亡 .hud 块(214-315)/build-bar(556-657)/机台按键/移动端 <920px 块(5870-5901)重写;新增 `#board` 全屏、`.hud-chip`(深色半透明+blur+金强调)、`.fab`(≥44px 圆形半透明)、boss-bar/banner/danger 现代化半透明重样式;清掉 5 处浅色主题的 deck 覆盖与 `--cab-*` 机台材质变量

7. 本地化补课:徽章标签用上现有孤儿 keys `hud.tower/score/coins/shield`;新增 `hud.towerNow/hud.towerBest`(当前/最高楼栋,现在是硬编码中文);悬浮钮 aria 复用 `pause.button/menu.help/menu.settings`
